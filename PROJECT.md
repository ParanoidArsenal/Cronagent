Название агента: AutomationDaemon — cron-демон для AI-автоматизаций с бюджет-контролем

Описание бизнес-процесса

У разработчика есть повторяющиеся задачи, которые должны выполняться по расписанию без его участия: проверка MR-ов каждое утро, синхронизация API-спек, утренний дайджест перед стендапом. Все они требуют LLM — проанализировать статус MR-ов, подготовить саммари, проверить CI-пайплайны. Сейчас это работает так:

1. Системный crontab: LLM-задачи в crontab не помещаются — нужен runner, история, бюджет. Записи разбросаны, нет единой картины: что запущено, что сломалось, сколько стоит.
2. Ручной запуск Claude CLI: claude --prompt "проверь мои MR" — каждый раз заново. Нет расписания, история теряется, бюджет не контролируется. Забыл запустить утром — результата нет.
3. Никак: задача слишком мелкая для отдельного сервиса, но слишком повторяющаяся для ручного запуска. В итоге — не автоматизирована.

Нет демона, который запускал бы LLM-задачи по расписанию, следил за бюджетом, отсекал сломанные задачи и отчитывался о результатах.

Выявление проблемы

- LLM-автоматизации по cron стоят денег — без бюджет-трекинга легко сжечь дневной лимит
- Повторяющиеся сбои не отсекаются — демон тратит бюджет на заведомо сломанные задачи каждый cron-тик
- Нет истории выполнений — невозможно понять, что запускалось, когда упало и сколько стоило
- Claude CLI не имеет встроенного планировщика — каждый запуск одноразовый
- Нет уведомлений о результатах — нужно вручную проверять, отработало ли задание
- Убийство демона во время выполнения теряет результат — нет graceful shutdown
- Имеющиеся инструменты (cron, systemd timers, CI/CD) не заточены под LLM-задачи с бюджетом и MCP

Ожидаемый результат (ключевое описание решения)

AutomationDaemon — это cron-демон на базе Claude Code, который запускает LLM-автоматизации по расписанию без участия человека.
Каждая автоматизация — markdown-файл с инструкциями для Claude и набором MCP-серверов (GitLab, Jira, Mattermost). Демон выполняет их по cron-расписанию, отслеживает стоимость каждого запуска и автоматически управляет бюджетом.

Демон самостоятельно контролирует надёжность: после 2 последовательных сбоев автоматизация попадает в skip-list и не тратит бюджет впустую; при исчерпании дневного лимита LLM-запуски останавливаются; при завершении процесса текущая задача доделывается, а история сохраняется. После каждого запуска демон отправляет webhook-уведомление в Mattermost — статус, стоимость, ошибки.

Автоматизации можно объединять в цепочки с передачей контекста (проверь MR-ы -> подготовь саммари -> отправь в Mattermost). Для управления демоном есть REPL, CLI и web-dashboard. Архитектура не привязана к конкретному AI-агенту — Claude Code можно заменить на Open Code или другой совместимый рантайм.

Таким образом повторяющиеся LLM-задачи работают сами: по расписанию, в рамках бюджета, с автоматическим отключением сломанного и уведомлениями в мессенджер.

Метрики

Мы будем считать эффективность решения по следующим показателям:

- Manual Effort: Снижение затрат времени разработчика на рутинные проверки (MR-ревью, API-синк, дайджесты) с ~30 минут/день до 0 минут — демон выполняет всё по расписанию.

- Task Reliability: Достижение 100% выполнения запланированных автоматизаций по cron-расписанию без ручного вмешательства.

- Budget Compliance: Дневной лимит LLM-расходов не превышен ни разу — бюджет-трекер останавливает запуски при исчерпании лимита.

- Fault Tolerance: Автоматическое отключение сломанных задач после 2 сбоев — 0 бюджета потрачено впустую на нерабочие автоматизации.

- Экономия FTE (Full-Time-Equivalent). В текущем процессе разработчик тратит ~30 мин/день на рутинные LLM-задачи (проверка MR, подготовка дайджестов, синхронизация). После внедрения AutomationDaemon — 0 минут.

При 250 рабочих днях/год это ~125 часов ручной работы. При стандартном рабочем годе в 1980 часов система экономит 0.06 FTE на одного разработчика. При команде из 15 разработчиков — суммарная экономия ~0.95 FTE, то есть один разработчик почти полностью освобождается от рутины для продуктовых задач.

Ресурсы

Один разработчик + Claude Code для ускорения

Инструменты

- Claude Code — AI-движок для автоматизаций
- TypeScript + Node.js 20+ — рантайм
- croner — cron-расписание
- PostgreSQL — хранение истории выполнений и метрик
- Next.js — web-dashboard для мониторинга
- Docker — контейнеризация демона

Интеграции

- Claude Code / Open Code — AI-агент для LLM-автоматизаций
- MCP-серверы — GitLab, Jira, Mattermost (из ai-pipelines)
- Docker — контейнеризация и изолированное исполнение
- PostgreSQL — хранение истории выполнений, метрик и данных сессий
- Mattermost — webhook-уведомления (планируется)
