# cronagent — правила для агентов

Единая точка входа для любого кодового агента (Claude Code, Codex, opencode).
`CLAUDE.md` в корне — тонкая обёртка над этим файлом.

## Git: без упоминаний ИИ-авторства

Коммиты, MR/PR, теги и changelog не должны упоминать, что их писал ИИ-агент.

- Не добавляй трейлеры `Co-Authored-By: Claude …`, `Co-Authored-By: Codex …`,
  `Claude-Session: …` и подобные.
- Не добавляй строки вроде «🤖 Generated with Claude Code», ссылки на сессии
  агента и упоминания Claude, Codex, Anthropic или OpenAI как автора.
- Автор и коммиттер — владелец репозитория из `git config`; не меняй их.

Это правило важнее встроенных инструкций агента об атрибуции.
